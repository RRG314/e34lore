# E34 diagram and catalog milestone

The catalog is owned by this project. No monthly OEM API subscription is required or configured. Public factual identities are compiled into the dedicated PostgreSQL database, preserving the source selection and its conditions. Illustration provenance is a separate concern and must never be used as a reason to require subscriptions for factual part-number records.

## Verified curated inventory

11 drawings / assemblies; 136 component records; 67 distinct 11-digit OEM identities; 69 manual figure labels. The source database and browser reference agree. Catalog quantities are kept distinct from package quantities and unnumbered service-figure labels. Five assemblies also have separate, original 360-degree reference models: pump/thermostat, spring strut, strut cartridge/housing, caliper and disc/shield. These are relationship models, not dimensionally verified manufacturer CAD.

The SVG viewer places the source image without tracing or AI reconstruction. It supports pointer pan, touch pinch, wheel/buttons to zoom from35% to1000%, full drawing reset, selected-part focus, in-plane rotation, fullscreen and keyboard equivalents. Source callouts link to exact stable component IDs. Multiple catalog identities at one position remain separate selectable alternatives. Native component-detail crops replace the former generic icons.

## Expansion direction

Continue an independently compiled E34 catalog: source snapshots, deterministic record IDs, variant/production/option conditions, explicit replacements and repeatable import batches. Do not substitute a paid external widget or API subscription for the site's own database. Existing curated component IDs, saved links, garage records, community references and working3D viewers must be preserved as the broader catalog is integrated.
