# Security

Report security issues through [private support](https://e34lore.com/support?category=other). Start the subject with “Security.” Include the affected page or source path, what you observed, and the affected version if known. Redact credentials, account data, VINs, and photos. Stop if you encounter another person’s data.

Use GitHub Issues for ordinary bugs and technical reference corrections. Keep security reports private until the maintainer has reviewed them and agreed on disclosure.
