# Contributing

Report bugs, parts errors, model details, and repair corrections in [GitHub Issues](https://github.com/RRG314/e34lore/issues/new/choose). Include the selected car and a part number, callout, measurement, or source page where useful. For an original photo or model, include the creator and permission you can grant. Describe large or unpublished files in the issue and contact [private support](https://e34lore.com/support?category=other) with the issue link to arrange delivery. Keep VINs, credentials, personal data, and production records out of issues and pull requests.

1. Fork [RRG314/e34lore](https://github.com/RRG314/e34lore), clone your fork, and create a branch.
2. Follow the [development setup](README.md#development). Make the change and run the relevant checks.
3. Push to your fork and open a pull request against `RRG314/e34lore:main`. Describe the change, link relevant issues, and list the checks you ran.

Maintainers review and merge changes. Public fork checks may wait for maintainer approval. Production runs through a separate release.

Link technical sources and state which vehicles they cover. Keep model credit and license terms intact. Scanner submissions stay separate from the production reference set until the source, permission, and labels are reviewed.

Submit original code under [Apache 2.0](LICENSE). For other material, state the applicable license or permission and give the creator and source. See [NOTICE](NOTICE).
